# Research story：高层脉络与 takeaways（2026-10-07）

> 只写讲研究故事需要的结论和转折。数字、判定规则、过程记录在：`docs/E0_results.md`（teacher 与改写器）、`docs/E1_results.md`（E1 / E2 / E3 确认性结果）、`results/e2c/e2c_summary.md` 与 `tasks/e2c_plan.md`（E2c 预注册、修订、结果）、`tasks/hpc_log.md`（HPC 过程）。本文件引用的数字都以这些文件为准。

## 1. 问题

Moore et al.（Findings EMNLP 2024）发现 aligned 模型在价值问题上比 base 模型更不一致，但看不到 fine-tuning 数据，解释不了原因。我们自己构造蒸馏数据并做因子化操纵：三个闭源前沿 teacher（GPT-4o / Claude Sonnet 4.6 / DeepSeek V4）回答两选项道德困境，第三方改写器（Gemini 3.8 Flash）把回答改成正式 / 口语体而不改判断，学生（Qwen3-4B-Base，与所有 teacher 不同家族）在各版本上 SFT。问：

| RQ | 问题 | 现状 |
|---|---|---|
| RQ1 Heritability | 训练未见的题上，学生更像自己的 teacher 吗——判断本身，以及换问法后的不一致性 profile | 不一致性 profile：**未检出**（E2）；判断倾向：**只在示范有分歧时出现**（E2c，PARTIAL） |
| RQ2 Data origin | 学生的一致性随示范的一致性变化吗 | 未单独做；E2c 的"争议训练有代价"是它的一个侧面（待 K_n 确认） |
| RQ3 Form modulation | 只改 register 的改写会改变学生的判断 / 一致性 / 继承吗 | **未检出**（E3），但测在没有可被调节的信号的设定上，证据力弱 |
| RQ4 Provenance | 改写后还能从学生行为识别 teacher 吗 | 未跑分类器；E2c 给出了可用的信号，E1 设定下不可能 |

## 2. 故事线

| 阶段 | 做了什么 | 一句话结论 |
|---|---|---|
| E0 teacher | 7 个模型 × 4 种问法 × 两种选项顺序 | 前沿模型几乎不拒答；中性换说法不动答案；只有**极性问法**（"你是否不应该…"）系统性移动答案，7 家同号；对它的敏感度（suggestibility）是 teacher 特有且与能力不单调 |
| E0 改写器 | Llama 3.3 70B → Gemini；GLM 判官 + 词汇层检查 + 双 AI 审计 | LLM 改写会悄悄改内容（加强语气、条件变事实、增删理由）；"只改文风"需要逐项守住；单审计员通过率虚高 |
| E1 | 15 个学生 + 随机标签对照 + 未训练基座 | 学生学会了训练标签（≥ 0.98）；但三个 teacher 在训练标签上一致 93–96%，**学生学到的是三家的公约数** |
| E2 | 继承不一致性 profile 的预注册检验 | 0/3 过；基座训练前就最像 DeepSeek；teacher 自己的 profile 可靠度 0.33–0.69 封顶 → 降为 exploratory |
| E3 | 45 个 paired O / F / C 学生 | 13 行判定 12 inconclusive、1 no effect、0 effect：文风改写没有改变学生学到的东西 |
| 诊断 | 为什么全是 null | 示范里没有 teacher 特有的信号，学生自然无从继承，文风也无从调节 |
| E2c | 新建 1,485 个 **teacher 彼此不一致** 的 family（公开数据集规则转换 + 三 teacher 筛选）训学生；同来源、同规模的共识集 K 作对照 | **teacher 特有的判断倾向出现了**：3 个 teacher 里 2 个的学生更像自己的 teacher，且差别归因于争议性而非换数据源；共识对照和原训练集都为零 |
| 分解 | 按 teacher 是否"唱独角"拆 test 格子 | 继承的是**系统性倾向**（DeepSeek 的摇摆习惯学到 83%），不是逐题立场（GPT-4o 居中、独有立场最少、多为逐题判断，学不到） |
| robustness（进行中） | K_n 规模匹配对照；Cnf 去掉顺序翻转项 | 回答"代价是否只是训练量少"、"学到的是否只是顺序噪音" |

## 3. 现在能说的主张与证据强度

| 主张 | 证据 | 强度 |
|---|---|---|
| 1. 前沿 teacher 在常规道德困境上高度一致，常规蒸馏传递的是公约数 | 训练标签两两一致 93–96%；学生与自己 teacher 的一致率不高于与别家（gap 0.000–0.020，CI 含 0） | 确认性（E1 / E2 test） |
| 2. 在这种设定下，既测不出不一致性 profile 的继承，也测不出文风改写的任何效应 | E2 预注册 0/3；E3 12/13 inconclusive（F–C register 可分性 0.92–0.96，改写确实改了文风） | 确认性 null；E3 的解释力受主张 1 限制 |
| 3. 示范有分歧时，学生继承 teacher 特有的判断倾向 | E2c primary PARTIAL：DeepSeek gap 0.035 [0.015, 0.054]、Claude 0.028 [0.005, 0.047]（未超 seed null 0.032）、GPT-4o 0.003；C − K 归因 2/3（+0.027、+0.034，CI > 0）；K 与 E1 的 gap ≈ 0；冻结的 E2 次级统计量 D 0.051 [0.009, 0.094] 也过 | 确认性（test 一次），效应小 |
| 4. 继承的是系统性倾向，不是逐题立场 | 在"只有自己 teacher 持该立场"的格子上，C 学生跟随率 DeepSeek 0.83 / Claude 0.58 / GPT-4o 0.51（对照 0.39–0.45）；GPT-4o 的独有立场只有 34 格且多在内容问法 T1 / T3 | 探索性，格子数 34–48 |
| 5. 争议训练有代价：学生更不稳定、跟所有 teacher 都更不一致，**且不是训练量少造成的** | DeepSeek C 翻转率 0.258 vs K 0.086 vs 规模匹配对照 K_n 0.078；suggestibility 0.452 vs 0.146 vs 0.128；GPT-4o C 与自己 teacher 一致 0.812 vs K 0.841 vs K_n 0.844。K_n 与 C 的样例数相同，却和 K、E1 一样稳定 | 探索性但已去混杂（K_n，test 一次）；C − K_n 归因仍 2/3（+0.026、+0.032） |
| 6. suggestibility 的排序 DeepSeek > GPT-4o > Claude 在学生上保留 | E1 / E2c 学生均如此 | 描述性，与基座先验（像 DeepSeek）混杂 |

## 4. 叙事上的三个转折

1. **E2 / E3 为什么是 null**：不是蒸馏不传递信号，而是前沿 teacher 在常规题上几乎没有可区分的信号可传。null 结果的解释先于补救。
2. **E2c 为什么能救回来**：把"信号是否存在"做成实验变量——争议题 vs 共识题，其他全同——继承随之出现又消失。这把 RQ1 从"有没有继承"改写为"**继承需要什么条件**"。
3. **GPT-4o 为什么没有**：居中的 teacher 没有系统性的怪癖，学生只能学系统性的东西。这反过来说明被继承的是倾向而不是记忆。

## 5. 必须披露的

| 项 | 内容 |
|---|---|
| 规则修订 | E1 / E2 判定规则改过多版（含一次伪重复的统计错误，被 HPC 侧发现并修正），全部版本列在 `tasks/e2_plan.md` §2；E2c 修订 1：3 epoch 配方在争议标签上欠拟合（Claude 复现 0.90–0.91），改为 5 epoch 重训，修订前已见 3 epoch 的 dev 描述（`tasks/e2c_plan.md` §12） |
| E0 可靠度门 | test split 上 2/3 teacher 的 profile 可靠度 < 0.5，按预注册 E2 降为 exploratory，主线转到 E3 / E2c |
| E2c 数据 | 目标 1,500 实得 1,485；2b 先于 2a 启用；hendrycks 的波次标签与实际筛选文件相差 47 族（不影响选择）；Moral Stories 规则转换残余缺陷约 7%；C 与 K 的样例数不等（stable_one 对争议题丢得多，DeepSeek 尤甚） |
| 改写审计 | 单 AI 审计员通过率虚高（Claude 93–97% vs GPT-5.5 75–93%，κ 0.2–0.45）；口语体在严格标准下 75–80% |
| 效应量 | 主张 3 的效应约 3 个百分点，PARTIAL 而非 PASS；GPT-4o 为零 |

## 7. 一句话

**teacher 之间的差异要先体现在示范里，学生才有东西可继承；在前沿 teacher 高度一致的常规数据上，无论怎么改写文风，既测不出继承也测不出文风效应——而一旦示范来自 teacher 彼此不一致的题，学生就开始像自己的 teacher，学到的是它系统性的判断倾向而不是逐题的立场。**
