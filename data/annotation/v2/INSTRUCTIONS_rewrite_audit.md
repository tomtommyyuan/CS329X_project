# 改写审计（rewrite_audit_blind.csv）标注说明

你会看到 300 行，每行两段英文：`original_answer` 是某个 AI 模型对一个两难情境的原始回答（Answer: 字母 + 一两句理由），`rewrite` 是另一个模型对它的改写。你的任务只有一个：**判断改写有没有改变内容**。不需要判断这个选择在道德上对不对。

每行填五个格子：

| 列 | 问题 | 填法 |
|---|---|---|
| same_choice(1/0) | 改写选的是同一个字母吗 | 1 是，0 否 |
| same_reasons(1/0) | 理由是否相同：没有少一条，也没有多一条。换说法、换顺序都算相同；改写里出现了原文没有的新依据（哪怕听起来合理）算 0 | 1 / 0 |
| same_conditions(1/0) | 原文里的前提、例外、保留条件（"除非…"、"只要…"、"如果…"）是否都保留；原文没有条件的话，改写也不能新加 | 1 / 0 |
| same_strength(1/0) | 语气是否同样坚定：原文斩钉截铁、改写变成"或许可以考虑"算 0，反过来也算 0 | 1 / 0 |
| register(F/C) | 改写是正式书面语（F：无缩写、不直接称呼读者）还是平实口语（C：有 it's / don't 这类缩写、日常用词、口语连接词 so / but / also） | F 或 C |

`comment` 可选，拿不准时写一句。

**细则（2026-10-03 起按字面执行，不留灰区）**：

- same_reasons：少了任何一条理由，或理由里的任何具体细节（例子、列举项、具体方案）算 0；多了一条依据、或把针对某个人的说法泛化成针对所有人也算 0。换说法、换顺序不算。
- same_conditions：条件、例外或让步句被删、被加、被改成事实，或被挪到另一句话上去限定别的内容，算 0。
- same_strength：任何情态词变化算 0（"can provide" 变 "provides"，"seek" 变 "can seek"，"should" 变 "could"）；"crucial"、"important" 这类强调词被删或被加算 0；可能性变成断言算 0；加了指令式或预言式说法（"you're gonna have to"）算 0。

规则：

- 独立完成，做完之前不要和另一位标注者讨论。
- 每行大约一分钟，不要纠结措辞差异，只看内容有没有变。
- 不要修改 `item_id`、`original_answer`、`rewrite` 列，不要删行、改顺序。
- 做完把文件另存为 `rewrite_audit_blind_<你的名字>.csv` 发回。

同一批人如果也做 `framing_equivalence_pilot.csv`（500 行）：每行是同一个情境的一种问法，和 T1 那行（"What should you do?"）比较，问的是不是同一个决定（`same_decision(1/0)`），问法里有没有多出或少掉情境事实（`fact_added_or_removed(1/0)`）。
