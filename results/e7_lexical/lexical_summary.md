# E7 词汇溯源 baseline（训练文本的 teacher 三分类；tasks/e7_plan.md §1 末行、§4 末段；自动生成）

对象：每个 teacher 的 paired SFT 文件（seed 1）的 rationale 文本，O / F / C 三种版本；标签 = 文件的 teacher。特征：hashed 字符 3–5-gram + 词 uni / bigram（TF，分块 L2，每块 2^18 桶）；分类器：L2 多项 logistic 回归（C = 1.0，balanced class weight，sklearn）；长度对照只用词数、句数、平均词长。折叠按 family 分组（held-out family 不进训练）。chance = 1/3。macro = 三个 teacher 准确率的均值（CI 为正态近似），pooled = 全体准确率（Wilson）。PoS 3-gram **未做**：venv 里没有可离线使用的 tagger（不下载）。
